# LLM Prompt Optimization & Verification Framework

A local Python CLI sandbox designed to isolate, test, and optimize structural prompt engineering patterns without relying on external API calls.

## Features
* **Zero-Shot Classification:** Demonstrates baseline LLM text categorization.
* **Few-Shot Categorization:** Enforces strict output formatting and pattern matching via context structuring.
* **Chain-of-Thought (CoT) Reasoning:** Programmatically illustrates step-by-step logic verification for complex problem-solving.

## How to Run
1. Clone this repository.
2. Run `python app.py` in your terminal.
3. Follow the interactive menu to execute different prompt methodologies.
